# Nova and Havoc: ChatGPT art prompts

How to use: start one new chat per pilot. Attach your artboard (the one with all six pilots) and the Rumble run strip as style references. Paste the STYLE BLOCK first, then ONE asset prompt per message. Generate in this order: portrait, run, idle, jump, fall, land, tagged. If a result drifts, attach the previous good one and say "same character, same scale, same colours".

Sheet rules the game pipeline depends on: flat pure green background #00FF00, character facing right, feet on one invisible baseline, every frame the same size, clear green gap between frames, no text, no labels, no shadows, no glow spilling onto the background, one row only.

## STYLE BLOCK (paste first, once per chat)

Polished 2D game art, toy-like chibi mecha, about 2.5 heads tall, chunky rounded armour plates, cel shading, clean dark outline, glossy edge highlights, high-contrast colours, same look as the attached artboard. Facing right. Pure flat green #00FF00 background for sprite sheets. No text, no watermark, no cast shadow, no background glow.

## NOVA (Scout Frame)

Design: slim, light, fast scout. White armour with cyan trim and panels. Swept-back angular head crest like small wing fins, cyan and white, with a tiny yellow accent at the brow. Black visor with one glowing cyan eye slit. Four-point star emblem glowing cyan on the chest. Pointed shoulder fins, small thruster pods on the back, white hands and feet with cyan toe caps. Lighter build than Patch, clearly the slimmest pilot.
